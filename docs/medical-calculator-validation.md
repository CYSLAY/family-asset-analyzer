## 计算验证

- 每千元保额基础费率独立索引对照：三个产品、所有供款期、1/21/41 翌年岁、男女、吸烟/不吸烟、A/B 地区、美元/港币，覆盖 672 次有效费率对照或缺失费率拒绝检查。
- 原生 Microsoft Excel 在临时副本中重算，未保存或修改原工作簿。所有推广、期满、EB 开关关闭，CIM3 C20 / CIE3 C17 / CIP2 C19 保额折扣置零。
- 六组原生场景：三产品分别按 41 岁男性不吸烟 A 地区、33 岁女性吸烟 B 地区；保额 100,000 美元，20 年缴。读取第 1/10/20/50 年保费、保证与非保证现金价值、保证与非保证保障金额。关键返回值已固化为测试断言，包括插值年龄的情况。
- 原表现金价值按标准年龄点插值，并保留参考保额归一化参数；不能把归一化常量误当客户优惠删除。最终保费已取消保额档位优惠。
- 测试同时覆盖：无折扣线性关系、非法输入、缴费期结束、混合币种人民币汇总、不同缴费年限合计，以及原有储蓄险计算回归。
