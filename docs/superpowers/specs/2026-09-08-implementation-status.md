# 全站可靠性升级实施记录

本记录对应已批准的 `2026-09-08-full-site-reliability-design.md`。分批发布不代表全项完成。

## 第一批：前端与计算回归

已实现并覆盖自动化测试：

- 姓名独填不达到首次上传门槛；有效完成度与模块导航状态分开。
- 已上传会话允许同步后续清空的字段；云端列表不再过滤低完成度的历史档案。
- 流动资金排除长期锁定资产；补充档案数据保留手填的零起始资金。
- 月供按剩余月数折算，到期停止；未知期限显示持续月供假设。
- 删除成员前确认关联数量，关联金额保留为家庭归属。
- 无负债需要显式确认；保险 10%–20% 的结论与状态颜色一致。
- 教育分项保留已知培训、食宿与学费，没有依据的不再虚构比例拆分。
- 顾问搜索结果同样每页五条。
- 未配置云端时写入/删除明确失败；旧同步响应不能确认较新的本地编辑，也不能改变另一客户状态。
- 客户网络重新连通时重新尝试自动同步；这尚不等于已完成持久队列和冲突处理。
- 储蓄险未启用提款时不校验默认提款年龄；批量撤销只影响相应格子，保留之后的独立修改。
- 放大窗口就地显示计算错误并可恢复；非法数字有文字反馈。
- 现金流放大窗口使用原生模态框；默认隐藏空白列，批量覆盖明确显示范围并确认。
- 储蓄险场景展示可动用现金及首次不足年份，不把保单余额当现金。
- 报告资产负债默认展开；隐私输入补充编辑提示；移除过期邀请码措辞与密码数字键盘限制。

浏览器检查：390、834、1440 CSS 像素关键路径；手机现金流模态窗口页面宽度 390/390，iPad 834/834，桌面储蓄险 1440/1440。桌面放大表格输入负数后显示错误，点击恢复重新呈现 11 行。尚未验证真实设备软键盘。
