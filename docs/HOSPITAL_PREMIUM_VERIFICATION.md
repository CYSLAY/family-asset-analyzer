# VIP 与 MCVIP 保费核验

核验日期：2026-09-08。仅扩展顾问医疗保障计算，不改客户数据或数据库。

## 原始来源

- [VIP 原始保费表](https://www.prudential.com.hk/tc/.galleries/pdf/brochure/pruhealth-vhis-vip-premium-table.pdf)：2025-10 生效，13 页，年缴标准费率。
- [MCVIP 原始保费表](https://www.dropbox.com/scl/fi/2i4o5j6bp6b7egtmzhemk/MCVIP_Premium-Table_AGY_TCEN_Jul24R.pdf?rlkey=ii80cdf5a566416vabqpk05ue&dl=0)：2024-07 生效，香港版，9 页。
- [MCVIP 官网产品说明](https://www.prudential.com.hk/sc/products/health/medical/premierflex-medical-plan/)：计划 1 至 4、自付额的地域区别及门诊附加保障。

用户随后提供的两份 PDF 与下载版本 SHA-256 完全一致；哈希存于 `hospitalRates.json`。未把第三方 PDF 全文或客户信息放入仓库。

## 分档及公式

VIP：PDF 第 2–9 页，按下次生日年龄、亚洲/全球除美国、港币/美元、自付额档位精确查表。首次投保 1–81 翌年岁；82 岁起费率供续保参考，表列至 121+。工具保守截止 121 翌年岁，不外推。

自付额：港币 0、20,000、50,000、96,000；美元 0、2,500、6,250、12,000。Excel `data` 中最高美元自付额表头错误写为 96,000；使用 PDF 第 9 页的 12,000，不改原 Excel。

MCVIP：PDF 第 2–4 页，按下次生日年龄、计划 1–4、零/有自付额查表。计划 1 仅有自付额；有自付额是内地 HKD10,000、内地以外 HKD30,000，美元分别为 1,250/3,750，并非任意二选一。新投保 1–70 翌年岁；71–100 为续保费率。101 岁及以上原 PDF 尚无费率，不计算。

MCVIP 门诊：第 5 页各年龄费率，仅叠加一次。采用基础费率加门诊费率，不再读取 Excel 已含门诊的组合列，以免重复。

MCVIP 表规定 USD1=HKD8：港币保单用原数；美元保单除以 8。美元保单折算展示币种时，另乘用户设定的展示汇率。VIP 直接使用 PDF 对应保单币种的费率，而非套用展示汇率推导。

年保费 = 对应年龄的基本计划费率 + 所选门诊费率。合计后转换展示币种并四舍五入至两位小数；期间总额逐年相加。分项独立显示到分，可能产生 0.01 舍入差异。无保额乘数、无默认 3% 涨幅、无折扣或税务扣减。当前标准费率不使用性别/吸烟/A-B 地区类别索引；个别风险核保加费不在本工具内。

## 全量核验

`scripts/extract-hospital-rates.py` 从 PDF 数字行解析，并与 Excel `data` / `data2` 逐年龄、逐档位对账：VIP 1,936 个数据，MCVIP 基础 700 个、门诊 100 个，共 2,736 个一致，零差异。

截图 41 翌年岁、USD 保单、HKD 展示、汇率 7.8514：VIP 亚洲零自付额 18,764.06；MCVIP 计划 2 零自付额 21,903.84；门诊 13,812.97；两项合计后换算 35,716.80（不是先把分项舍入后相加的 35,716.81）。其他截图费率均设独立测试。

逐年合计复用每份保险各年度的实际测算保费，不能把首年值重复填入后续年度。混合危疾险时，危疾险供款期结束后停止累计；医疗险只在所选测算年数内累计，不代表保单期满或后续无需缴费。

## 报价边界

这是指定版本标准年缴费率测算，不是未来续保或个别核保报价。两份表均不含保险业监管局征费；未来标准费率可能变动。MCVIP 核保风险类别还可能涉及国籍、居住国家等，不能仅凭通用基础信息宣称最终准确报价。页面明确展示版本和来源，不将旧版费率描述为实时费率。
