# 顾问专用储蓄险计算器

## 范围与隔离

顾问侧边栏「储蓄险计算」是独立测算工具，不在客户自测导航中出现，渲染与切换入口均检查顾问模式。原有现金流储蓄险场景未被替换，不修改客户 JSON、数据库或云端同步逻辑。

两份产品参数分别在当前浏览器 `sessionStorage` 暂存，以顾问用户名分区；不保存客户姓名、联系方式或原工作簿的作者身份。不是跨设备档案保存。退出会话或清理浏览器后可能丢失，页面有明确说明。

## 计算实现与边界

- `scripts/extract-insurance-workbook.py` 提取两表公式及必需的 data3/data4 参考列。价格基础表没有方案输入，其已计算数值作为版本化静态数据。
- `insuranceFormulaEngine.ts` 是有界、惰性引用的解释器，不执行 JavaScript eval、宏、HYPERLINK 或网络请求。未知函数、无效查表、无解 IRR、循环引用均明确失败。
- 原表身份文字一致性判断两侧统一为 JoJo，不公开原作者信息。它不影响财务规则。
- `insuranceCalculator.ts` 将输入映射到原单元格，直接计算逐年余额与 IRR、优惠、累计供款、提款、融资和最高提款迭代公式。
- 年期 0 是投保时点，退保时点保单余额计入总提取；IRR 沿用原表现金流时间约定。表内 IRR 尚未回本时原表隐藏为 0，界面显示 `—`，不表示没有损失。
- 优惠仅复现 2026-08-03 文件，不代表当前有效。资格、核保、正式保证值与非保证利益须以正式利益说明及条款核实。
- 网页会阻止互斥优惠、融资与重复储蓄并用、超出测算数据年期、未缴完即退保等无效输入；不是核保规则检查器。
- 界面保留 5 / 10 年、长周期、固定表头首列、局部横向滚动、放大窗口、保证明细开关、隐藏空白提款列。向下填充只改同列后续年度，操作前确认并提供撤销。
